What the repository contains  
The repository contains CookedGrabber.py, a Python-based information-stealing malware (info-stealer) that:

Steals Discord authentication tokens from the local Discord application data, and enabling full account takeover
Harvests session cookies from Chrome, Edge, Brave, Firefox, Opera, Vivaldi, and Chromium — enabling unauthorized access to victims' Twitter/X, Instagram, Netflix, and other accounts bypassing two-factor authentication   
Exfiltrates saved passwords from browser credential stores  
Sends all stolen data to attacker-controlled Discord webhooks (the script requires the operator to insert their webhook URL at line 290)  
Collects system information (IP address, OS details, CPU info, MAC address, country) for victim profiling  
The README explicitly instructs users how to use stolen cookies to log into victim accounts ("To bypass website security you must be already connected to your personal account to generate all cookies needed… replace your personal id account cookies with the grabbed victim account cookies").
